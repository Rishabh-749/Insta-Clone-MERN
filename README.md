# 🚀 Local Setup

## Clone Repository

```bash
git clone https://github.com/Rishabh-749/Insta-Clone-MERN.git
cd Insta-Clone-MERN
```

---

# Backend Setup

```bash
cd Backend
npm install
```

### Create `.env`

```env
PORT=8080
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
IMAGEKIT_PUBLIC_KEY=your_public_key
IMAGEKIT_PRIVATE_KEY=your_private_key
IMAGEKIT_URL_ENDPOINT=your_url_endpoint
```

### Start Backend

```bash
npm run dev
```

---

# Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```
